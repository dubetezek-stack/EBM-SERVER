# BeRich 💰

Um aplicativo premium de organização financeira inteligente que lê e processa suas faturas de cartão de crédito em PDF e organiza automaticamente seus gastos. 

## Funcionalidades
- Interface moderna (Glassmorphism, Dark Mode)
- Extração de PDF (NuBank, Itaú, Bradesco) com categorização automática
- Previsão de parcelas (Forecast) 
- Persistência de banco de dados SQLite
- Prevenção contra upload de duplicatas

## Como rodar localmente
Execute os comandos na raiz do projeto:

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) com seu navegador para acessar a interface.
